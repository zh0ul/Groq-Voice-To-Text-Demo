# Voice-to-Text with Groq

This project is a web application that allows users to transcribe audio files or live recordings into text using Groq's API.

## Features

- **Transcribe Audio/Video Files**: Upload audio or video files and get the transcription.
- **Live Recording Transcription**: Record audio directly from the browser and get the transcription.
- **Settings**: Configure API key, model, response format, temperature, and prompt.

## Getting Started

### Prerequisites

- A modern web browser with support for audio recording.
- A Groq API key. You can get one from [Groq Console](https://console.groq.com/keys).

### Usage

1. Open `index.html` in your web browser.
2. Enter your Groq API key in the settings section.
3. Select the desired model, response format, and temperature.
4. (Optional) Provide a prompt for better transcription accuracy.

#### Transcribe Audio/Video Files

1. Click on the "Transcribe File" tab.
2. Upload an audio or video file.
3. Click the "Transcribe File" button.
4. The transcription will be displayed in the text area.

#### Transcribe Recording

1. Click on the "Transcribe Recording" tab.
2. Click the "Start Recording" button to start recording.
3. Click the "Stop Recording" button to stop recording.
4. Click the "Transcribe Recording" button.
5. The transcription will be displayed in the text area.
